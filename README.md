# fd-releases

APK release hosting repository for FD Apps (via GitHub Releases).

## Setup
1. Create a public GitHub repository named `fd-releases` under `fahadtech8`.
2. Push this `README.md` to the `main` branch.
3. Upload APK binaries under **Releases → Draft a new release** using app-prefixed tags.

## Recommended Tag Naming
- `fd-youtube-v64` → `FD_YouTube_v64.apk`
  - URL: `https://github.com/fahadtech8/fd-releases/releases/download/fd-youtube-v64/FD_YouTube_v64.apk`
- `fd-insta-v15.80` → `FD_InstaPro_v15.80.apk`
- `trucaller-v26.21.6` → `Truecaller_v26.21.6.apk`
- `cinemavip-v3.2.0` → `CinemaVIP_v3.2.0.apk`
